How to run this script on the pi


1. install packages and update
    sudo apt update
    sudo apt install -y python3-venv libgl1


2. create and start virtual enviroment
    python3 -m venv .venv
    To start > source .venv/bin/activate
    To end > deactivate

    to download ultralytic
    pip install -r requirements.txt




3. CONVERT THE MODEL TO NCNN
    yolo export model=model/weights/best.pt format=ncnn


4. RUN IT
    python main.py
